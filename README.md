# Made by Us — prototype

A voluntary self-assessment label for demoscene productions: how much of it was made by its credited
authors ("us", guests included), condensed into one opinionated fridge-sticker grade (A+ … F), with the
answers always one click away.

This version offers **three questionnaires of increasing precision** so the group can decide how much
simplicity is acceptable. The **Compare** tab grades the same typical productions with all three.

Open `index.html` in a browser (works from `file://`), or serve the folder:

    python3 -m http.server 8000   # then http://localhost:8000/   (comparison: /#compare)

Tests (scenario grades, encoding, group rules, exhaustive monotonicity per variant):

    chromium --headless=new --virtual-time-budget=20000 --dump-dom "file://$PWD/test.html" | grep -E "FAIL|PASSED"

## Shared principles

- Generated by AI counts the same as bought, downloaded, ripped or licensed: **not ours**.
- Most or all of a category not being ours is much worse than some of it.
- The framework is asked first and printed on the label ("Built with TiXL"). A third-party engine or
  demotool, or a mostly generated framework → **B at best** — unless the production's authors are also
  that tool's authors ("Built with TiXL — our own tool"), which counts as an own framework.
- Does not count: AI advice and debugging, AI suggestions you rewrote, tools that do not ship
  (DAW, Blender, compiler, packer), OS, graphics API and standard libraries.

Content categories: effects code, visuals & design, 3D & motion, audio, direction & text.

## The variants

| | Quick `q1` | Standard `s1` | Detailed `d1` |
|---|---|---|---|
| Questions | 3 | 6 | 6–11 |
| Framework | engine list + "are you its authors?" | same | same |
| Per category | — (counts only) | 4 steps | 5 steps + "reworked?" |
| Weights | none | none | effects code ×0.75 |

**Quick** — how many categories are *mostly* not ours (0 / 1 / 2+), how many *partly* (0 / 1 / 2–3 / 4+).
Partly: A+, A, B, C. One mostly → D (E with 2+ partly). Two or more mostly → F.

**Standard** — per category: all ours / a detail isn't / a notable part isn't / most or all isn't.
Points detail 1, notable 3: 0 → A+, 1 → A, ≤3 → B, ≤7 → C, more → D. One "most" → D (E with 2+ notable),
two or more → F.

**Detailed** — per category: all ours / detail / notable / most / all, and if not all ours, "substantially
reworked by us" or "used mostly as-is". Points 0.5 / 2 / 6 / 10, ×0.6 if reworked, effects code ×0.75.
0 → A+, ≤1 → A, ≤3 → B, ≤6 → C, ≤10 → D, ≤18 → E, more → F. Most → D at best; all → E at best (D if reworked).

All three cap at B for a third-party framework.

The first two answer characters are the framework: `0` own code, `1` TiXL, `2` Notch, `3` TouchDesigner,
`4` Werkzeug, `5` Unity, `6` Unreal, `7` Godot, `8` other third-party, `9` own but mostly AI-generated;
then `0` "it's ours" / `1` no for listed tools, `_` otherwise. Add tools in `ENGINES` in `variants.js`
(append only — the index is part of the link).

## The link is the record

    https://<site>/#s1/1100030/pz94176
                    │  │      └ optional production: dz<id> = Demozoo, pz<id> = Pouët
                    │  └ one base-36 character per question: the option index (0 = best), "_" = not asked
                    └ variant and its scoring version

Short form for NFOs and scrollers: `MBU-s1-1100030-pz94176`.

Scoring changes get a new variant version (`s2`, …). Once labels exist in the wild, old versions must
keep decoding and rendering with their own scoring.

## Files

- `core.js` — grades, records, production ids, label SVG (shared)
- `variants.js` — the three questionnaires, their scoring and the comparison scenarios
- `app.js`, `index.html`, `style.css` — page
- `test.html` — tests

QR codes use `qrcode-generator` from cdnjs; without it the label renders without a QR code.
Live at https://pixtur.github.io/madebyus/ (GitHub Pages, `main` branch, root). Labels made from a local
`file://` copy still point their QR code there (`PUBLIC_BASE` in `app.js`).
